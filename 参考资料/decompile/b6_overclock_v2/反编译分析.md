## 一、实验模式超频（核心能力）

`WaspWingViewModel.enableExperimentalMode(enabled)` 是本包的核心能力：

```
setExperimentalRunMode(
    enabled,         // 开关
    coldLevel + 1,   // 实验档位 = 制冷档位 + 1（超一档）
    null, ...)
```

**自动同步机制**：`onDeviceInfoUpdate` 里设备回报 `experimentalRunModeValue` 后，若该值与 `realColdLevel + 1` 不一致，**自动重新下发** `setExperimentalRunMode(1, realColdLevel + 1)`——保证实验模式在设备端持续生效。该自修复逻辑的伪代码与其副作用（UI 闪烁）见 [../b6_devtool/反编译分析.md §4.2](../b6_devtool/反编译分析.md)。

**逆向要点**：实验模式的本质是把制冷档位推高 1 档（突破正常 UI 上限）。对 b6x 增强计划的启示：正常档位上限 300 被 SDK 或固件限制，实验模式是解锁更高制冷的开关。

**常量印证**：飞智散热器开发者工具包的 `WaspWingInfo.EXPERIMENTAL_RUN_MODE_COLD_LEVEL = 230`（0xe6）恰为其制冷上限 229（0xe5）+ 1；本包该常量 = 300（0x12c），等于本包的制冷上限（本包上限已放到 300）。

| 参数范围常量 | 逐项对照见 [通用6](../通用.md#通用6-参数范围与硬件上限)（本包 = 该表左列） | 逐项对照见 [通用6](../通用.md#通用6-参数范围与硬件上限)（V2 = 该表右列，冷 / 风速上限均更大） |

| 在 b6x 增强计划中的角色 | 主要钩子目标（`...waspwing.experimental`） | 同源第二包名，模块以同一套钩子逻辑覆盖 |
