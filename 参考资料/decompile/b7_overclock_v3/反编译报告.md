## （2）散热器控制 API（最重要）

### 是否有 WaspWing 相关类？

**是的！** 该 App 完整集成了飞智 WaspWing SDK，与 B6X 使用**同一套 SDK**。关键是 B7/B7X 的设备代码也被包含在内。

### WaspWing SDK 核心文件（共 47 个文件引用）

核心类在 `com.flydigi.sdk.waspwing` 包下：

| 文件 | 说明 |
|------|------|
| `WaspWingInfo.java` | 散热器数据模型（Parcelable） |
| `a.java` (`WaspWingDataInteractionController`) | **核心控制层**，发送 BLE 命令 |
| `WaspWingManager.java` (t9.j 混淆后) | 管理器单例，封装所有 API |

## （3）BLE 连接流程

### BLE 服务 UUID

GATT 服务定义在 `WaspWingDataInteractionController`：

| UUID | 用途 |
|------|------|
| `0000ffe0-0000-1000-8000-00805f9b34fb` | 服务 UUID |
| `0000ffe1-0000-1000-8000-00805f9b34fb` | 数据写入特征值 |
| `0000ffe4-0000-1000-8000-00805f9b34fb` | 数据通知特征值 |
| `00002902-0000-1000-8000-00805f9b34fb` | CCCD（客户端特征配置描述符） |

### BLE 扫描流程

扫描实现在 `AbstractBluetoothController` 中：
- 使用 `BluetoothAdapter.startLeScan()`（旧 API）或 `BluetoothLeScanner.startScan()`（新 API）
- 过滤逻辑：通过自定义 `u` 接口过滤设备，默认使用 `WaspWingManager.a` 实现
  - 过滤条件：RSSI 阈值（默认 -90） + 设备名称匹配

### BLE 连接流程

连接实现在 `c0.java`（`BluetoothGattCallback` 子类）：
1. **连接建立** → `onConnectionStateChange` → 状态 `BluetoothProfile.GATT_CONNECTED`
2. **GATT 服务发现** → `onServicesDiscovered` → 查找 UUID 匹配的服务
3. **启用通知** → 写入 CCCD (`00002902-...`) 启用 Indication/Notification
4. **数据交互** → `AbstractDataInteractionController.R0()` 发送数据到特征值

`WaspWingDataInteractionController` 的回调：
- `S1()`: 连接成功 → 创建 `WaspWingInfo`，通知监听器
- `T1()`: 断开连接 → 清除连接状态，通知监听器
- `P1()`: 设备发现
- `R1()`: 绑定状态变化

### 扫描 UI

`ScanFragment` 实现了多个接口：
- `com.flydigi.sdk.bluetooth.m` - 连接状态监听
- `e0` - BLE 设备列表更新
- `t9.i` - WaspWing 数据更新

### 权限检查

使用 `com.blankj.utilcode.util.PermissionUtils`（BlankJ UtilCode 库）进行运行时权限检查，但没有独立封装"蓝牙权限检查"方法。权限检查散落在各 Activity/Fragment 中。

| `GAIABREDRService` | CyberFox/Gaia 手柄经典蓝牙服务 |

| 特性 | B6X | B7/B7X |
