飞智温控增强 · PID 分段倍率表 · 多簇曲线重合的处理

本页按 lsp模块/daemon/ki_cut.h（C 端权威实现，与 KiCutTable.java 逐值对齐）1:1 复刻求值规则，用于直观查看多条簇曲线重合时「生效值」怎么选。

先记住这条规则
多簇重合时，每个冷值取「离该轴整段参照值 M 最近」的那一簇；距离并列（|d₀−d₁| ≤ 1e-3）取更小倍率。
M 不是逐点平均，而是每条轴一个常数：该轴上各簇在自身覆盖区间内、所有整数冷值处候选值的总体平均（区间长的簇占权重大）——所以图上 M 是一条水平线。
该轴只有 1 个候选时直通（不受 M 影响）；某簇在该轴全留空 = 无候选、不参评。旧口径「逐点平均」已废弃——恰好两条线时两边到逐点平均恒等距，规则失效，故改为整段一个常数。
求值规则（据此页 JS 逐条实现，可逐条对照 ki_cut.h）
  1. 每个簇内的点按冷值升序排列；同一冷值只保留先出现的那一个（ki_cut_normalize）。单簇点数上限 32。
  2. 三条轴互相独立：KDP 倍率 / 升倍率 / 降倍率。某个倍率框留空 = 该点在这条轴上不作为控制点，从该轴的控制点序列里剔除，折线由左右相邻的未留空控制点直接连线（ki_cut_lerp 跳过 KI_CUT_SKIP_* 的点）。
  3. 折线：相邻控制点之间线性插值；小于最小冷值取首点、大于最大冷值取末点（两端平推）；某轴一个控制点都不剩 → 该轴恒为 100（不削）。
  4. 多簇逐轴独立：参照值 M ＝ 该轴上各参评簇（该轴有控制点者）在其自身覆盖区间内、所有整数冷值处候选值的总体平均（每个整数冷值算一次；无候选处不计）。每个冷值取候选中 |v − M| 最小者；并列（|d₀−d₁| ≤ 1e-3）取更小倍率（ki_cut_axis_eval + ki_cut_nearer）；该轴只有 1 个候选时直通。
  5. 冷值留空 = 占位行：整点不参与任何轴求值，只用于编辑/落盘往返。整簇都是占位行 → 该簇清空（不参评）。
  6. 没有任何参评簇（0 簇 / 全占位 / 该轴全留空）→ 该轴 100（不削）。
验收例（页内预设「★ 两簇不交叉（用户验收例）」）：簇1 左 70 / 右 90，簇2 左 60 / 右 80 → M = (70+90+60+80)/4 = 75（两段都是直线且跨度相同，故 M ＝ 四个端点值的平均）。
左段：|70−75|=5 < |60−75|=15 → 生效 70（取较高的那条，已不再是「取最小」）；右段：|80−75|=5 < |90−75|=15 → 生效 80；中点：|80−75| = |70−75| → 并列 → 取更小 70。
为什么废弃「逐点平均」：逐点平均 M(x)=(a(x)+b(x))/2 时，两候选到 M(x) 恒等距 → 只剩并列、规则失效。改成整段一个常数 M 后才有区分度。
实现口径：与源逐句一致（ki_cut_axis_eval / KiCutTable.axisEffective）：M 用梯形公式在整数冷值上求和；等距判定用 TIE_EPS = 1e-3，并列取更小倍率。
