## 单位与口径约定

- 温度一律以**整数码**存储，`1 码 = 0.1 ℃`；`BATT_BASELINE = B = 350 码 = 35.0 ℃`。
- 温度口径统一用**峰值（半幅）**，峰峰值 = 2 × 峰值。
- `R` / `d` / `x_i` 单位 **码**；`P` / `Q` / `T1` / `T2` / `M` 单位 **码²**；θ 单位 **码**（门控半宽，配置值即码值、内部零换算，5 码 = 0.5 ℃）；`r` / `g_up` / `g_down` / `scale` / `ki_rate` / 削减下限 / `N` / `α` **无量纲**。

## 读图提示

- **主链只有一条纵线**：推入 → 求值 → 护栏 → 门控 → 基机制 → 方向系数 → 缩放钳制 → EMA → 积分速率。
  短路判定**不在主链上**：它挂在「温度未变」的分支里（`B2 → SK`）。
- **约定值从侧边接入**：`M`（`G2`）、θ（`TH → H`）、`α`（`AL → Z`）三个紫虚节点只是给主链供参数，不改变主链走向。θ 与 α 不再藏在门控 / EMA 节点的正文里。
- **三个"不干预"出口**：读数无效 `R2`、整轮冻结 `SK2`、PID 重算但机制无新值 `SK3` —— **都不产出新 scale**；温度未变即不步进 EMA，`s` 原样保持。其中 `SK2`/`SK3` 的窗口本就**没有**新样本（"样本已入窗"的旧说法是错的：温度未变与"有更新"互斥）。
- **四个"干预退化"出口**（样本不足 `DEG1` / 硬护栏不过 `DEG2` / 门控关闭 `DEG3` / 触到削减下限 `Q2`）**全部汇入 EMA**，写 1.0 或下限值，没有任何一条绕开平滑直接改 `ki_rate`。
- **`CAL` 子图不是运行时自动标定链**：它只是 T1 / T2 默认值的来源说明。`T1` / `T2` 各自独立配置、不做真机标定，改 θ 不再联动它们。
- **计数口径**：本图 **36 个节点**（不含 `subgraph CAL` 这个容器；沿用旧口径把容器也算作 1 个节点则为 37）、**40 条边**、**9 个判定节点**（`B` / `R` / `SK` / `M` / `G` / `H` / `I` / `P` / `T`），条件均已写原文与具体数值，未留占位符。
- **样式统计**：紫虚（约定值）共 5 个：`M`（`G2`）、θ（`TH`）、`α`（`AL`）、`CAL1`、`CAL2`。原来的三路方向分支（`P−Q` 大于 / 小于 / 等于 0）已由 `max()` 写法统一，相关判定节点已删除。`X` 是**防御样式**（其条件对常数 20 / 30 恒真），不算退化出口。
- **静默点不变**：对称三角波下 `P − Q` 精确为 0 → `g_up = g_down = 1` → 两侧同额降 `r`；`P+Q = 0` 时 `r` 取到最大 0.6714（默认档），两侧一同落在削减下限。
- **配置项与诊断字段**（`T1` / `T2` / `M` / θ / 削减下限 / `N` / `α` 及其护栏、体检字段与 `pid_log` 的容量限制）见 [../待办.md](../待办.md) 对应条目，本图不重复列出。
