## B. 我方条目被推翻 / 需修正

### B2 需修正（非撤回）
1. **我方 R2-A1 S2-3 的「约每 25s」** → 修正为 **约 15–22s**：`forceReconnect` 的 10s 防抖不构成约束（下一次触发 ≥15s）；周期 = tick 重连延迟（≤5s）+ 首包延迟 + 15s 停滞计时。对端的「约每 15s」则是下限，两者都不精确。

## C. 待裁定事实分歧（附只读命令）

1. **B7X SDK 的 mode 语义**（对应 A2-S2-4）：`a.E2` 未被 jadx 反编译。需要原 farsef APK（仓库内没有）跑 `D:\tools\jadx\bin\jadx.bat --show-bad-code <apk>` 后读 `com.flydigi.sdk.waspwing.a.E2`；或真机让 B7X app 连 B6X 设备下发固定功率，抓 `0x21/0x22/0x23` 命令字节。
2. **死区是否真的导致停滞误判**（对应 A2-S2-3）：需要 `adb logcat -s WaspWingTempCtrl | grep "锁死检测: 回传停滞"`；该行会打印「冷<回显> RPM<回显> ≠ 目标 冷<lastBcast> RPM<lastBcast>」（`MainHook:2874-2876`）。若回显与 lastBcast 相同，对端因果链不成立。
3. **API 25 可达性**（对应 A2-S2-8）：`core/build.gradle.kts:10` 确为 `minSdk = 25`，但需 LSPosed 1.8 的最低 API 证据（发布说明）+ 目标机 `adb shell getprop ro.build.version.sdk`；若 ≥27，该条不可达。
4. **COLD_TEMP 负零**（对应 A2-S3-14）：冷端处于 (-1,0)℃ 时执行 `adb shell cat /data/local/tmp/tempctrl_b6x.status | grep COLD_TEMP`，并需要一帧 `getTemperature()=0 且 getTemperatureDecimal()>0` 的原始值；没有该帧就无法证明是模块公式还是 SDK 编码丢符号。
5. **对端 E2 引用的 `arbitrate_and_keep_one` 不存在**：`grep -n "arbitrate_and_keep_one\|static void arbitrate_apps\|evict_app_if_eligible" lsp模块/daemon/tempctrl.c` → 实际为 `arbitrate_apps`（约 3261）与 `evict_app_if_eligible`（约 3254）。不影响其结论（机制存在，名字不同）。
6. **对端 S3 计数**：自述 16、实列 17（`sed -n '/### S3/,/## C/p' 审查/2026-11-13/R2-A2-hook层.md | grep -c '^| \`'`）；属报告笔误。

## D. 双方共识条目清单

1. B7X `:remote` 进程被注入后重复写 status / 重复注册（双方 S1）。
2. 两个 B6X 包共写同一 status 文件（对端 S1、我方 S2；同根因，严重度差异）。
3. status 主参数块多 getter 共用一个 try，单点失败连坐后续字段。
4. 未下发（`lastBcast=-1`）时停滞判据误触发 `forceReconnect`。
5. 导出广播接收器无来源校验、无参数钳制。
6. `.tmp`+rename 原子写会退化为截断直写（权限/多写者）。
7. status 写盘失败会跳过同 tick 的 `checkCommandStall`。
8. `connectedControllers` 无淘汰、可线性增长。
9. `StartupTiming`「6 个」vs `SUB_COUNT=8`。
10. `AppFiles.diagnose` 引用不存在的「进展文件未决项」。
11. 模块无任何单元测试。
12. B6X 的 runFetchLoop 队列替换本身安全（volatile 字段、构造后赋值、peek 仅 runFetchLoop 调用）。
13. 广播 action/extra、status 字段、uiprefs、临时停止文件协议两侧对称；`GATE_LE` 只写不读为有意兼容。
14. `mainHandler` 惰性加载修复了 fork 期 Looper NPE（现存的只是无同步竞态）。
15. B7X 自动进入控制页的类名/extra 与宿主反编译一致。
16. 九个 getter 在三份反编译宿主中均存在（可关闭对端 E8 的「未逐一取证」缺口；命令：`grep -c "getColdRunLevel\|getTemperatureDecimal\|getSpeed"` 于三份 `WaspWingInfo`）。
